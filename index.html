💡 엑셀 업로드 가이드 및 처리 방식

  • 컬럼 구성: API 이름 | API 서비스 URL | 사용법 사이트 URL | 카테고리
  • 하이퍼링크 자동 추출: API 서비스 URL 셀에 하이퍼링크가 설정된 경우 텍스트 대신 실제 링크 주소를 자동으로 추출하여 반영합니다.
  • 중복 URL 처리: 이미 등록된 API 서비스 URL이 존재할 경우 기존 데이터를 업데이트(Update)하며, 존재하지 않으면 신규 추가(Insert)합니다.
  • 안전성 보장: 업로드하는 엑셀에 없는 기존 API 데이터는 삭제되거나 변경되지 않고 안전하게 유지됩니다.
